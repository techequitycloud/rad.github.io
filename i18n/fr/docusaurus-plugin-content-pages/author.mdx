# Dr Shiyghan Emmanuel Navti {#dr-shiyghan-emmanuel-navti}

Dr Shiyghan Emmanuel Navti rédige et maintient l'ensemble de la documentation de ce
site — les guides de certification, les parcours de labs pratiques et les références
des modules de **RAD Platform** par [Tech Equity Cloud](/about) — et conçoit
la [RAD Console](https://radmodules.dev), le portail de déploiement qui sous-tend cette
documentation.

Chaque guide suit la même méthode de travail : déployer d'abord l'infrastructure réelle
dans un projet Google Cloud actif, puis documenter ce qui a été déployé,
vérifié et exploité — afin que le support d'étude corresponde à des ressources cloud
inspectables plutôt qu'à des diapositives.

## Certifications Google Cloud {#google-cloud-certifications}

L'auteur détient six certifications Google Cloud en cours de validité :

| Certification | Niveau |
|---|---|
| [Associate Cloud Engineer (ACE)](https://cloud.google.com/learn/certification/cloud-engineer) | Associate |
| [Professional Cloud Architect (PCA)](https://cloud.google.com/learn/certification/cloud-architect) | Professional |
| [Professional Cloud Developer (PCD)](https://cloud.google.com/learn/certification/cloud-developer) | Professional |
| [Professional Cloud DevOps Engineer (PDE)](https://cloud.google.com/learn/certification/cloud-devops-engineer) | Professional |
| [Professional Cloud Security Engineer (PSE)](https://cloud.google.com/learn/certification/cloud-security-engineer) | Professional |
| [Cloud Digital Leader (CDL)](https://cloud.google.com/learn/certification/cloud-digital-leader) | Foundational |

Chaque certification renvoie à sa page officielle Google Cloud décrivant
l'examen pour lequel elle est délivrée.

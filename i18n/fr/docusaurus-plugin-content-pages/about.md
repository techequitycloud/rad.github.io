# À propos de RAD Platform {#about-rad-platform}

**RAD Platform** est une plateforme de formation pratique aux certifications Google Cloud conçue par
**Tech Equity Cloud**. RAD signifie **Rapid Application Deployment** (déploiement rapide d'applications) — à ne pas
confondre avec les outils low-code de « Rapid Application Development ».

Plutôt que des diapositives ou des bacs à sable simulés, RAD déploie une infrastructure préconfigurée
et réaliste, fidèle aux usages du secteur (des « modules »), dans votre **propre projet Google
Cloud** : chaque objectif d'examen de certification correspond ainsi à une ressource cloud réelle
et inspectable que vous avez vous-même déployée.

## Ce que couvre la plateforme {#what-the-platform-covers}

- **Plus de 520 guides de référence des modules** — des références de configuration pour déployer
  plus de 190 applications open source et cloud-native sur Cloud Run et GKE Autopilot
- **Plus de 345 labs pratiques** — des parcours guidés déployer → vérifier → exploiter → observer → démanteler
  dans votre propre projet GCP
- **Des cartes de labs et des guides par section de certification** pour sept certifications
  Google Cloud : Associate Cloud Engineer (ACE), Professional Cloud Architect
  (PCA), Professional Cloud Developer (PCD), Professional Cloud Database
  Engineer (PCDE), Professional Cloud Network Engineer (PCNE), Professional
  Cloud DevOps Engineer (PDE) et Professional Cloud Security Engineer (PSE)
- **Des principes de conception** qui documentent les standards d'ingénierie appliqués à chaque module
